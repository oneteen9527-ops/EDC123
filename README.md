# 风力发电投资基金平台

前后端分离：
- `backend/` Express + SQLite + JWT + 定时收益任务
- `frontend/` React + Vite（用户端 + 管理后台）

## 功能
- 用户注册/登录（邀请码绑定推荐关系）
- 首页产品购买、设备收益进度、邀请页面、个人中心
- 充值/提款申请与流水
- 管理后台：会员、充值、提款、设备、产品配置
- 收益自动计算：定时任务按分钟模拟“每日收益”，达到总收益上限自动停止
- 多级邀请返佣（系统配置可调整）
- 图表、风险提示、多语言切换、公司介绍
- 管理员权限分级基础表结构

## 启动
```bash
cd backend && npm i && npm run dev
cd frontend && npm i && npm run dev
```

默认管理员账号：`admin / admin123`。
